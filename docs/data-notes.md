## 4. 统计摘要与目标关系事实（T 系列，只陈述事实）

## 7. 对建模的影响与限制（供 A4–A7 阅读）

1. **标注只能按超额程度划界**：T3 证明附件1 无一单"赔付≥索赔"，题面三分类的分界必为连续负差额轴上的程度分界，且 T6b/T8 给出"赔付水平↑→相对超额典型值↓"的单调结构，与题面 C4 的方向约束一致（事实基础已备，具体边界由 A4/A5 按题面 C2/C5/C6 推导）。
2. **配送超时时长重度截断**：64.6% 质量贴在 427864 硬墙上，原值区分度有限；_触墙/_为负/_sl 列是可用形态，阈值化使用需谨慎。
3. **保价金额不是有效上限**：T9 66.82% 赔付超保价，凡假设"赔付≤保价"的规则在本数据上不成立。
4. **万单理赔率 9–12% 哨兵缺失**：已 NaN+标记，模型需支持缺失或使用指示列；不要把 -0.99 当真实比率。
5. **附件2 目标缺失**：Q2 评估只能走附件1 内验证框架（对应 A1 歧义 D3 仲裁口径）；附件2 的 `索赔金额` 在位，方式1（预测赔付→与索赔比较）链路数据齐备。
6. **Result 填写约束已核验**：运单号 1..2792 逐行对应，Q2/Q3 两空列即落位处（§1.3 F1–F4）。
7. **数据体制稳定**：附件1→附件2 漂移极小（§5），附件1 训练成果外推附件2 的分布风险低；主要泛化缺口是 ID 冷启动 6–8%。
