## 0. 总体设计立场与坐标系声明（D11-① 执行）

**声明（本设计的全局前提）**：问题 1 的三类划分在 **(x, e) 绝对超额坐标系** 上构造并主用：

- x = 实际赔付金额（元），e = 索赔金额 − 实际赔付金额 = −索赔差额 ≥ 0（超额幅度，货币量纲）；
- 等价地，在题面 L19 定义的索赔差额轴 d = x − y（T3：附件1 全部 11167 行均为负，P50=−282.9、min=−4464、max=−0.08）上，划分边界是**连续负差额轴上的程度分界**（A3 §7 第 1 条）；
- 边界为两条非降函数 g1(x) ≤ g2(x)（判"诉求偏高"需 e ≥ g1(x)，判"严重超额"需 e ≥ g2(x)），满足 A2-04 的单调结构。

**两种参数化的关系（必须写入论文的报告项）**：T6b 显示按赔付十分位，绝对超额典型值随 x 单调加深（差额均值 −160.5→−1317），而相对超额 r = e/y 的典型值随 x 单调下降（中位 0.8731→0.5319）。二者并不矛盾：数据一致的边界 g1(x) 呈**次比例增长**（慢于 x 的增长），故"绝对容许超额随赔付增大"（A2-04）与 A3 给 A4 提示的"赔付越高、容许相对超额越小"（T6b 阶梯）是**同一边界在两种坐标系下的对偶表述**。本设计主用绝对超额坐标系以直接满足 A2-04 的 g1/g2 非降要求（若主用相对坐标系，则数据一致的边界将随 x 递减，与 A2-04 冲突，且会使高赔付段几乎无法被标注为偏高/超额，造成类别被赔付水平完全混淆）；相对口径作为论文中的对偶报告项（A3 §8 对 A2-04 的"参数化警示"）。

**选择依据清单**：C4（L21 单调性）、A2-03/A2-04（双变量联合边界 + 单调参数化）、T3（差额全负、只能按超额程度分界）、T6b/T8（赔付—超额联合阶梯结构）、A3 提示（负差额轴 + 相对口径对偶）、D11-①（显式声明）。

### 2.2 输入变量（附件1_clean 实际字段名）

规则输入**仅两个字段**（C3 硬约束：标注同时与差额和赔付金额有关；C7 定义式；A2-03；决策建议 D20）：

- `实际赔付金额`（x，边界函数的自变量）；
- `索赔差额`（d，a3_06 衍生列；e = −d 为划界轴）。

其余全部特征**不进入规则**，只进入 Q2/Q3 模型（避免规则与题面 L33 指定的两个分析对象脱钩）。

### 2.3 规则结构：分层条件分位边界（主路线）

**结构形式**：对每个运单，依 x 所在分箱 b(x) 查两道边界，序贯判定（次序固定：先超额后偏高，A2-20）：

```
e_i = −索赔差额_i
若 e_i ≥ g2(x_i)        → 严重超额
否则若 e_i ≥ g1(x_i)     → 诉求偏高
否则                     → 合理诉求
```

三类互斥完备、每单唯一标签（C1、A2-02；两金额列 0 缺失，A2-02 已证实无需兜底路径）。

**边界形式候选（N4-02，A5 择一）**：

1. **等频分箱常数阶梯 + 跨箱单调化（主候选，菜单 M1-2）**：x 等频分 B 箱（B∈{10,20} 起步，设计变量），箱内取 e 的 τ1/τ2 分位数，再用保序回归（PAVA）跨箱单调化。直接实现 C4 阶梯单调；箱间跳变由单调化消除。T8 的十分位×五分位阶梯矩阵是其数据形态依据。
2. **单调参数式（备选，M1-3 变体）**：g_j(x)=a_j+b_j·x^{α_j}（b_j≥0），可在 log x 上拟合（T1：log10 空间 P1–P99 跨 2.41 个数量级近线性）。参数最少、C15 陈述最简。
3. **单调约束分位点回归（平滑备选，M1-5）**：以 x（或 log x）为自变量对 e 做非降约束的条件分位数回归，边界连续平滑；复杂度高，作论文中的平滑性对照。

**参数估计流程（A5/A6 执行，本文只定结构）**：

1. 分箱：x 等频分 B 箱（尾箱样本保障：B 上限受尾部计数约束，见风险节）；
2. 箱内分位：对每箱计算 e 的经验分位数 Q_{e|bin}(τ1)、Q_{e|bin}(τ2)；
3. 全局软校准（N4-03）：选 (τ1, τ2) 使**总体占比**落入 C2 先验带——合理诉求 ≥85%、严重超额 <3%（软目标，允许偏离；初值 0.85/0.97 由 L21 两数字直接换算）；校准方式：给定 τ 扫描总体占比，按 V1 准则取带内且裕度合适的解；
4. 单调化：对每道边界跨箱保序（M1-2 路线）或直接用非降参数式/非降约束回归（N4-02 路线 2/3）；
5. 交叉核验（非主路线）：M1-4 混合模型/密度聚类对 (log x, e) 拟合，检查分位边界是否落在类间低密度谷（C6 密度差的数据证据；按 A2-20 须离散化为显式条件后方可作为标签，本设计仅用作证据不产出标签）。

### 2.4 目标函数与约束

**设计目标（形式化）**：选 θ=(τ1, τ2, B, 形态族) ∈ Θ，使验收维度 V1–V8 综合最优；数值化与权重归 A5 定稿。

**硬约束**：C1（三类固定）、C3（输入仅 d 与 x）、C4（g1/g2 非降）、C7（定义式）、A2-20（确定性唯一标签）。

**验收/选优准则应考核的维度（V 系列，候选定义；具体数值 A5 定）**：

| 编号 | 维度（约束来源） | 候选度量 |
|---|---|---|
| V1 | 占比先验符合度（C2，软） | 三类总体占比与先验带的偏差；合理诉求 ≥85%、严重超额 <3% 带内取裕度合理解；偏离则如实报告（A2-06） |
| V2 | 单调性（C4） | 单调化后跨箱违例数 =0；Spearman(g_j, 箱中位 x)=1 |
| V3 | 同类紧凑（C5） | 分箱内同类 e（等价 d 取负）的稳健离散度（IQR/MAD）与该箱总体离散度之比，越小越紧凑 |
| V4 | 密度差（C6） | 两个视角：①密度对比——各箱内三类单位 e 长度的质量份额（合理诉求应显著高于严重超额）；②离散度对比——合理诉求类 IQR/MAD 相对严重超额类之比。以密度为主视角（"密集程度"原义），离散度辅证（A2-07 双操作化） |
| V5 | 业务序一致性（C1/C18） | 三类差额中位严格有序：严重超额 < 诉求偏高 < 合理诉求（差额越负超额越深，T3 口径）；各类 x 分布非退化（每类横跨多个 x 分箱，规则不得退化为单纯的赔付门槛） |
| V6 | 稳健性 | bootstrap 重抽规则参数 → 边界参数 CI 宽度与标签翻转率；多种子/多折下占比稳定（M4-3/M4-4） |
| V7 | 可解释性（C15） | 参数个数、规则陈述长度（分箱表 + 一句话路径为最优） |
| V8 | 下游支撑（C11/C13） | 严重超额绝对行数足够支撑 Q3 训练（n1=11167、<3% 先验 ⇒ 量级至多数百行，A2-19）；占比不得趋零或显著超先验 |

**选优结构建议（A5 定稿）**：先做硬筛选（V2 违例=0；V1 带内；V5 序成立），再在通过集上对 V3/V4/V6 加权综合（V7/V8 作为门槛检查）。
