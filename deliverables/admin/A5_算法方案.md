## 1. Q1 标注规则：参数估计算法

### 1.1 统一输入
附件1_clean：$p_i$（实际赔付金额）、$c_i$（索赔金额）→ $u_i = c_i - p_i$，$i = 1..11167$。

### 1.2 分箱分位数基准（M1，兼作 M2/M3 的拟合目标）
1. 按 $p$ 等频分 $K=20$ 箱（每箱 ~558 条）；
2. 每箱计算 $\hat q_{\tau}^{(k)} = $ 箱内 $u$ 的 $\tau$ 分位，$\tau \in \{\tau_1, \tau_2\}$；
3. 对序列 $\{(\bar p_k, \hat q_\tau^{(k)})\}_{k=1..K}$（$\bar p_k$ = 箱中位赔付）做 **PAVA 保序回归**（非降）得节点表；
4. 预测时：节点间线性插值，两端用边界箱斜率线性外推（并设 $T_j(p) \ge T_j(p_{\min})$、$u \ge 0$ 的常识夹取）。

### 1.3 参数曲线拟合（M2）
对每个 $\tau$：最小化 $\sum_k w_k \big(\hat q_\tau^{(k)} - \alpha - \beta \bar p_k^{\gamma}\big)^2$，$\gamma$ 网格 {1, 1.2, 1.5, 2}，$w_k = n_k$；约束 $\alpha \ge 0, \beta > 0$；解析内层（线性 LS on 变换后设计阵）× 外层网格 $\gamma$。**要求 $T_2(p) > T_1(p)$ 全域成立**，违者淘汰该 $(\gamma)$ 配置。

### 1.4 条件分位数回归（M3）
statsmodels 未确认安装 → 自实现**分位数梯度提升**成本高；降级实现：以 $\log u$ 对 $\log p$ 的线性分位回归（单纯形法，自实现代价可控）或直接弃用 M3（若 1.5 的择优中 M1/M2 已充分）。**决策：M3 仅在 M1/M2 的 S1-S4 得分不足时启动（记录于 decisions.md）。**

### 1.5 $(\tau_1, \tau_2)$ 网格择优
- 网格：$\tau_1 \in \{0.85, 0.86, 0.88, 0.90\}$，$\tau_2 \in \{0.97, 0.98, 0.99\}$，形态 ∈ {M1, M2}；
- 每组合计算 S1-S4（**v3 修订**：v2 的 IQR 比与间距检查经诊断不成立——赔付邻域内池 IQR 在密集区过小致偏高类比值>1 属正常（池集中于低 u 而偏高类居中尾），间距检查对稀疏类有统计假阳性；区间连续性由规则结构（类区域=两单调边界间的 u 带）数学保证。修订如下，A0 批准生效）：
  - S1 占比（%合理, %偏高, %严重）：合理 ∈ [85.5%, 90%]（对 C3 留 0.5pp 边际）、严重 ∈ [1.5%, 3%)（对 C2 严格<3%，下限 1.5% 保障问题3 少类训练样本 ≥160）；
  - S2 单调性违例数（网格 200 点扫描，须为 0）；
  - **S3-v3 类内紧凑（区间占比）**：每个赔付十分位内，类样本 u 极差 / 该箱全体 u 极差，对箱取均值；三类均 < 1（同类样本只占邻域 u 跨度的一部分，显著小于随机指派的 ~1.0），逐类报告；区间连续性由规则形式（类区域 = 单调边界间的 u 带）保证，作结构性说明。
  - **S4-v2 密度对比**：每个赔付十分位内，对该箱全体 u 做高斯 KDE（Silverman 带宽），在各类样本点处取密度值求均值再对箱平均；要求 mean_f(合理)/mean_f(严重) > 1（合理类位于高密度区、严重类位于稀疏尾部，直接对应题面 C7）。
- 择优规则（词典序）：S1 合规 → S2 零违例 → S3 有序成立 → S4 密度比最大 → 参数简洁（M2 优先于 M1，若 S4 差距 <5%）。
- **最终规则冻结**：形态 + $(\tau_1, \tau_2)$ + 参数表写入 output/tables/rule_final.json，此后所有阶段只读不改。

### 1.6 附件1 标注输出
全量标注 CSV + 占比对照表（题面 C2/C3 对照列"题面软约束 / 实测"）。

## 2. Q2 回归：训练与评估算法

### 2.1 折协议
- `KFold(n_splits=5, shuffle=True, random_state=2025)`；
- 每个 fold：train 早停（eval_set=valid，MAE 度量，early_stopping_rounds=100，最多 2000 棵）。

### 2.2 模型配置（A4 §2.2 表）
- 特征：数值列直接用；类别列用 `category` dtype 传入 LGBM（内置类别处理）；高频 ID 用 A3 频次编码列。
- 超参网格（3×2×2=12 组，按 fold-1 MAE 预筛取前 3 组再做完整 5 折）：
  - learning_rate ∈ {0.05, 0.1}
  - num_leaves ∈ {31, 63}
  - min_child_samples ∈ {20, 50}
  - objective ∈ {L2, L1} 单独成列（M-L2/M-L1）；M-LOG = L2 on log1p；
- 基线 B0（中位数）、B1（log-log 线性）同折评估。

### 2.3 指标与检查
- MAE（主）、RMSE、MAPE（排除 $p<1$ 的极端小值：MAPE 全量报告 + 排除后报告）、WAPE；
- 检查：$\hat p \ge 0$ 占比 = 100%（M-LOG 结构保证，其余 clip）；$\hat p > c$ 越界率（报告）；
- 选中模型冻结为 `q2_model_config`（含特征清单与超参），5 折 CV 指标 + 全量重训模型用于推断。

## 3. Q3 分类：不均衡处理与评估算法

### 3.1 折协议
标签生成后 `StratifiedKFold(n_splits=5, shuffle=True, random_state=2025)` —— 路线A、路线B 共用同一折索引（E4 可比性，A2-09）。

### 3.2 三方案
- **A-clsW**：`class_weight` = 反频率 $n/(3 n_k)$；
- **B-resample**：训练折内 SMOTE 不可用（imblearn 未确认）→ **随机过采样**严重/偏高类至配比 (1 : r1 : r2)，网格 r1∈{0.5, 1.0}, r2∈{0.3, 0.5}（占多数类比例），验证折保持原始分布；
- **C-thr**：标准 LGBM（无权重）概率输出 → 先验校正 $\tilde q_k \propto q_k / \pi_k^{w}$，$w$ 网格 {0.5, 1.0}，或在验证折上直接网格搜索三类判决阈值 $(\theta_1, \theta_2)$ 使宏 F1 最大。
- 统一评估：宏 F1（主）、accuracy、每类 precision/recall/F1、混淆矩阵；选优规则：宏 F1 最大，并列时严重类召回高者优先。

### 3.3 路线B（E4）
同折内：Q2 最优配置在该折训练 → $\hat p$ → $u^B = c - \hat p$（clip ≥0）→ 问题1 冻结规则判类 → 与真实 $y$ 对比。输出同款指标 + 混淆矩阵。

### 3.4 显著性/稳健
- 5 折指标的均值 ± 标准差报告；路线A vs B 做逐折配对比较（差值均值±std，5 折样本小，只做描述性统计，不做检验，论文如实说明）。

## 4. 推断与提交管道（E6）
1. 全量 11167 重训 Q2 最优模型 → 附件2 推断 $\hat p$（M-LOG 则 expm1）；
