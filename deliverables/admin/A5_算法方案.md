### 2.2 主流程伪代码

```
读 附件1_clean.csv → x, d；e = −d（T3：d 全负 ⇒ e>0，min=0.08、max=4464）
for B in {5, 10, 15, 20}:                                  # §2.3 机制
    edges = np.quantile(x, [k/B], k=1..B-1)                # 等频分箱（T1 无质量点 ⇒ 边界不重合）
    bin(b_i) = x_i 所在箱（1..B）
    for τ1 in {0.85,0.86,0.87,0.88,0.89,0.90}:             # §2.4 机制
      for τ2 in {0.97,0.975,0.98,0.985,0.99,0.995}:
        if not (τ2 > τ1): continue
        q1[b] = np.quantile(e | bin=b, τ1);  q2[b] = 同理 τ2
        g2 = PAVA(q2, bin序=1..B, increasing=True)          # §2.5
        g1 = min(PAVA(q1, increasing=True), g2)             # 双边界保序一步修正
        L_i = 判定(e_i, b_i):                                # 序贯判定（先超额后偏高，A2-20）
            if e_i ≥ g2[b_i]:   "严重超额"
            elif e_i ≥ g1[b_i]: "诉求偏高"
            else:               "合理诉求"                      # 同值取高序：e==g1 判偏高
        计算 V1–V8 度量（§2.7）→ L0 硬筛选
θ* = 对通过 L0 的组合按字典序 (L1, L2, L3, L4, L5) 取最优（§2.6）
用 θ* 全量重算边界与标签 → 输出 1–5；bootstrap V6（B=1000，§2.7）
```

### 2.3 分箱数 B 的确定机制

- **候选集 {5,10,15,20} 的来源**：A4 D13 指定 {10,20} 起步；T8 十分位×五分位联合矩阵是数据形态参照（10 与 5 均在参照内）；A4 §2.7 指出严重类尾部箱稀薄风险，故补 B=5 作稀疏回退档；15 为等间隔中间档。上界 20 由尾部计数约束校验：等频下箱均 n1/B=11167/20≈558 行，τ2 上探 0.98 时箱内期望尾部计数 558×0.02≈11 ≥ 5，分位数可估；B>20 将使该期望 <5（不可估），故 20 为数据约束下的上限。
- **最终取值**：不预设，由 §2.6 字典序在候选集内择优（V7 兜底层偏好小 B，V6 稳健性可否决小 B）。

### 2.4 τ1/τ2 网格与步长的确定机制

- **τ1 下缘 0.85 与 τ2 下缘 0.97**：由 C2（L21"合理诉求不低于 85%、严重超额通常小于 3%"）直接换算（D14/N4-03），非自由参数。
- **τ1 网格 {0.85..0.90, 步长 0.01}**：上缘 0.90 的对应偏差贡献为 5pp，大于 L1 先验邻域阈 3pp（§2.6），保证"邻域约束而非网格截断"为有效约束；步长 0.01 ⇔ 占比分辨率约 112 行（n1=11167），高于自检所需精度。
- **τ2 网格 {0.97..0.995, 步长 0.005}**：步长 0.005 ⇔ 约 56 行，约为严重类总量（3%×11167≈335）的 17%，可分辨；上缘 0.995（严重约 56 行）**将被 L0 的 V8 下界淘汰**（100 行下界 ⇒ 1−τ2 ≥ 0.9% ⇒ τ2 ≤ 0.991）——网格故意上探以让机制显式淘汰，避免人为截断。
- **组合可行性由 L0 过滤**：C2 推论"偏高 ≤12%"（A1 §三 C2 行）⇒ τ2−τ1 ≤ 0.12（如 (0.85,0.98) 偏高≈13% 被淘汰）；V8 扩展"偏高 ≥100 行"⇒ τ2−τ1 ≥ 0.009。两约束夹出的可行格点约 30–40 个/B，总量 ≤ 160 组合，全量计算 < 10 s。
- **序约束**：τ2 > τ1（g2 ≥ g1 的构造前提）。

### 2.5 跨箱保序单调化（PAVA）与双边界保序

- 单边界：对箱序 b=1..B（等频箱按 x 升序，用箱序号作自变量即可，避免中位点并列）以 `sklearn.isotonic.IsotonicRegression(increasing=True)` 做 PAVA，输出非降序列。PAVA 单遍合并违例段（池化平均），复杂度 O(B)，天然化解尾箱稀薄（相邻稀薄箱与邻箱合并）——A2-07 回退预案的落地形态之一。
- 双边界：先对 q2 做 PAVA 得 g2；再对 q1 做 PAVA 后取 `g1 = min(g1_iso, g2)`。依据：两个非降序列的逐点 min 仍非降（保序不破坏），且逐点 min 保证 g1 ≤ g2；又因同箱经验分位恒有 Q(τ1) ≤ Q(τ2)（τ2>τ1），min 修正仅在 PAVA 池化交叉时起作用，属一步修正而非迭代。
- 数值稳定：e 恒正（T3），g1 下界自动 ≥0；分位数用 numpy linear 插值，无迭代收敛问题。

### 2.6 占比校准与择优目标函数（C2 软先验的字典序实现）

记 s_合/s_偏/s_严 为 θ 下三类总体占比。择优流程：

- **L0 硬筛选**（任一不满足即淘汰）：
  - V2：跨箱违例数 =0 且 Spearman(g_j, 箱序)=1（PAVA 后应为恒真，作断言）；
  - V1：s_合 ≥ 0.85 ∧ s_严 < 0.03 ∧ s_偏 ≤ 0.12（C2 及其推论，带检查非截断）；
  - V5(a)：median(d|严重) < median(d|偏高) < median(d|合理)（严格序，T3 口径）；
  - V8：100 ≤ n_严 ≤ 0.03·n1(=335) ∧ n_偏 ≥ 100 ∧ n_合 ≥ 9492（下界 100 为与 K=5 分层折协议耦合的约定：每训练折约 80、每验证折约 20 个少数类样本，折级 recall/precision 才有最低支撑；上界即 C2）。
- **L1 先验邻域（占比锚定）**：D_prior = |s_合−0.85| + |s_严−0.03| + |s_偏−0.12| ≤ 0.03。依据：D14/N4-03 以 C2 换算的 (τ1,τ2)=(0.85,0.97) 为初值，"允许偏离、不作硬截断"（A2-06）；阈 0.03（总偏差 3pp）为约定值——约为偏高带宽度的 1/4，既落实"软"先验又给结构判据留出实际选择空间，防止占比差异主导选择（A2-06 禁止为凑占比反向操纵规则）。
- **L2 密度（C6 主视角）**：D_geo 最大。定义 D_b = (n_合,b/w_合,b)/(n_严,b/w_严,b)，w_合,b = g1_b − min(e|b)、w_偏,b = g2_b − g1_b、w_严,b = max(e|b) − g2_b（单位 e 长度的质量份额）；D_geo = exp( mean_{b: n_严,b≥1} ln D_b )（几何平均，跨箱可比）；n_严,b=0 的箱不进入平均（其密度比记 +∞ 单列报告）。依据：A4 V4 明示"以密度为主视角"。
- **L3 紧凑（C5 辅证）**：R_合 + R_偏 最小，其中 R_c = Σ_b n_c,b·IQR(e|c,b) / Σ_b n_c,b·IQR(e|b) ∈ (0,1]（IQR_b<1e-12 的箱跳过；T1 无质量点保证分母有效）。依据：A4 V4"离散度辅证"，故列密度之后。
- **L4 稳健（V6）**：bootstrap 标签翻转率最小（定义见 §2.7 V6）。
- **L5 兜底字典序**：B 最小（V7 奥卡姆）→ D_prior 最小（靠近先验角 (0.85,0.97)，D14 初值依据）→ (τ1, τ2) 字典序。
- **定稿报告义务**：θ* 的实际占比与 C2 带的偏离如实写入自检表与论文（A2-06；若 L0 无解即触发 §7 回退 R-02）。

### 2.8 复杂度、收敛性、失败处理（Q1）

- 复杂度：全网格 ≤160 组合 × O(n)（每组合一次分箱归属 + 分箱内分位 + O(B) PAVA）≈ 10 s 量级；bootstrap 1000 次 × O(n log n) ≈ 数十秒。内存可忽略（n1≈1.1 万）。
- 收敛性：PAVA 单遍即达全局最优（凸问题投影），无迭代发散风险；全流程确定性（无随机源，除 bootstrap 由种子 20251004 驱动）。
- 失败处理：某箱 e 全同值（IQR=0）→ 跳过该箱 V3 统计并记日志（T1 无质量点，预期不触发）；L0 无解 → 触发 §7 R-02 停步上报；PAVA 后 g1>g2 理论不可能（min 修正），出现即断言失败上报。

### 2.9 可选模块（默认执行轻量版，均在同一脚本内）

1. **M1-5 平滑对照**（N4-02 路线3）：`HistGradientBoostingRegressor(loss="quantile", quantile=τ_j, monotonic_cst=[+1])` 以 x（或 log10 x）拟合 e 的条件分位曲线，仅作论文平滑性对照与 V2 对照，不产标签；statsmodels 缺失的等价路径（§1）。
2. **M1-4 交叉核验**（不产标签）：sklearn `mixture.GaussianMixture`（分量数 2/3）对 (log10 x, log10 e) 拟合，报告类间谷位置相对 g1/g2 的偏离，作为 C6 密度差证据；按 A2-20 不作标签来源。
3. **对偶报告**（A4 §0）：分箱计算相对超额 r=e/y 的 τ 分位阶梯，仅写 q1_对偶报告.csv 供论文对偶表述。

### 3.3 双变体定义与 smearing 修正公式（M2-4/D15）

- **变体 A（log10+smearing）**：z = log10(实际赔付金额)（T1：skew=1.905、log10 空间近线性、z∈[1.338, 3.501] 条件数良好）；模型拟合 z；预测反变换
  `ŷ = 10^ẑ × φ`，其中 **smearing 因子** `φ = (1/m) Σ_j 10^(z_j − ẑ_j^OOF)`（Duan 型非参数校正，通用方法论；ẑ^OOF 用**内层 4 折 OOF** 残差以避免训练内乐观偏差：CV 每折在"该折训练部分"内部再做 4 折 OOF 估 φ_fold，最终全量模型用全量 5 折 OOF 估 φ_final）。同时报告不校正的 10^ẑ 作为消融行。
- **变体 B（原尺度 Huber）**：直接拟合 y，`objective="huber"`；α（分位参数）∈ {0.5, 0.9}（依据 T1 重尾需较强鲁棒档与默认档对照）。反变换偏差为零，但预测 clip ≥0.01。
- **变体裁决**：同一验证框架（§3.6）下按 WAPE 主、MAE 辅择优；论文报告双变体对照，不预设胜负（D15）。

### 3.6 评估协议与指标定义式（D09/D19/D11-②）

- **切分**：①主口径=分层 5 折（按 log10 目标十分位分层以稳住重尾折分布；K=5、shuffle、种子 {20251004, 20251005, 20251006}，N4-06）；②稳健口径=行序外推：前 ⌈0.8×11167⌉=8934 行训练、后 2233 行验证（U3：赔付中位十块 KW p=0.0091、首末块 +17.4%，D19/D11-②）。两口径结论须定性一致方可写入论文（D11-②）。
- **指标定义式**（金额恒正，WAPE 分母无失效风险，T1 P5=21.77>0）：
  - WAPE = Σ_i |y_i−ŷ_i| / Σ_i y_i（主）；
  - MAE = (1/n)Σ|y_i−ŷ_i|（辅）；
  - RMSE = sqrt((1/n)Σ(y_i−ŷ_i)²)（报告项，注明重尾敏感性 M2-6）；
  - SMAPE_保护 = (1/n)Σ 200|y_i−ŷ_i| / max(y_i+ŷ_i, 1.00)（分母下限 1.00 元为形式保护，实际 y+ŷ ≥ P5 量级远大于 1；M2-9）。
- **报告形态**：折间均值±标准差（5 折 × 3 种子分别汇总）；**bootstrap CI**——主口径将 5 折 OOF 预测池化（每行恰一预测），重抽行 B=1000 次、取百分位 2.5/97.5 得 WAPE/MAE/RMSE 的 95% CI；行序口径在 2233 行验证集内同法。B=1000、水平 95% 为通用方法论惯例（M4-4 提示库能力，本实现用 numpy 手写），标注"约定"。
- **重复行**：R5 的 25 组（50 行）保留于全部口径，论文注明其对 CV 估计影响可忽略（A4 §3.5 第 4 条）。
- **最终交付**：按协议选定的（变体×模型×超参）在全量 n1 重训 → 预测附件2 2792 行 → 写 `附件2_赔付预测.csv`（两位小数）；Result 列的写入统一在 a6_06（§6）。

### 4.2 主路线（方式2 直接分类）伪代码（含两级杠杆 M3-4+M3-5）

```
L = 附件1_风险标注.风险标注（三分类）;  F = §3.2 特征集
# 杠杆一（M3-4，训练期类权重）
w_i = ( n_train / (3 × n_{c_i}) )^γ          # γ=1 即均衡化权重；γ∈{0,0.5,1} 由内层选出（C13 消融素材）
# 杠杆二（M3-5，验证期后验乘子校正）
L̂ = argmax_c  s_c · p_k(c)，s = (1, s_偏, s_严)   # s_合理 锚定为 1（乘子对整体缩放不变，仅 2 个自由度）
for seed in {20251004, 20251005, 20251006}:      # 主配置 3 种子
  StratifiedKFold(5, shuffle=True, random_state=seed)  # 按标签分层
  for each 外折 (train, valid):
    # —— 嵌套校准（防泄漏：校准只用训练部分，验证折不参与，通用方法论）——
    inner 4 折 OOF 于 train：
       for γ in {0, 0.5, 1}:
         训练 LGBM 多分类(objective=multiclass, num_class=3, sample_weight=w(γ), 早停 100)
       for (s_偏, s_严) in {0.5,0.7,1.0,1.5,2.0}×{0.2,0.3,0.5,0.7,1.0,1.5,2.0}:   # §4.3 网格机制
         L̂_oof = argmax_c s_c p_c → 宏F1、预测占比
    (γ*, s*) = 满足占比带约束中内层 OOF 宏F1 最大者（§4.3 校准目标与并列规则）
    以 γ* 全量 train 重训 → valid 后验 p → L̂ = argmax_c s*_c p_c
  汇总折间均值±std；池化 OOF → bootstrap CI(1000, 95%) 于 宏F1 与 严重类 recall
行序 80/20 口径：前 8934 行内做嵌套校准与训练 → 后 2233 行评估（同 γ/s 网格）
最终：γ*, s* 于全量 n1 重训 → 附件2 后验 → argmax(s·p) → 附件2_风险预测.csv
```

### 4.3 阈值/先验校正（M3-5）的计算步骤与校准目标

1. **乘子网格依据**：γ=1 权重会把严重类后验系统性抬高约 1/s_严 倍（M3-4 提示"概率被系统性抬高，需阈值再校正"），故 s_严 网格向 0.2–0.7 下探以覆盖" deflate "区；γ=0 时少数类饥饿需 s_严>1 抬升，网格上探至 2.0。s_偏 网格 {0.5..2.0} 覆盖中间类双向修正。**网格端点为协议约定（覆盖两个杠杆的相互作用域），网格内取值由数据（内层 OOF）决定**。
2. **校准目标（写明）**：在**内层 4 折 OOF** 上，最大化 macro-F1，**约束**预测占比落 C2 带（s_合≥0.85 ∧ s_严<0.03，预测口径同 Q1 自检）；**并列时**依次以：严重类 recall 高者 → 预测三类占比与 Q1 实际占比的 L1 距离小者 → (s_偏, s_严) 字典序小者。依据：A4 §4.5"macro-F1 主 + 严重类单列 + 占比 vs C2 带（软）"；与 Q1 的先验语言同构（M3-5 菜单提示）。
3. **两级杠杆的耦合评估**：γ 与 s 联合在内层选出，外折指标如实反映联合工作点；γ 网格的三个取值本身即消融点（见 §4.5）。
4. N4-07 边界带降权（默认关闭）：仅当消融显示宏 F1 提升才启用；δ_j = 0.1×g_j(x)（约定，A2-20 不确定度报告的落地形式），启用时样本权再乘 exp(−|e−g_j|/δ_j) 于边界带内。

### 4.5 消融矩阵清单（C13 素材；均双口径；种子 20251004 单种子以控预算，主配置另跑 3 种子）

### 4.6 评估协议（Q3）

- **双口径（D19）**：分层 5 折（按标签分层、3 种子同 §3.6）+ 行序外推 8934/2233；两口径定性一致方可入论文（D11-②）。
- **指标（M4-5）**：macro-F1（主）；每类 precision/recall/F1；混淆矩阵；**严重超额 recall 与 precision 单列**（A2-19）；预测三类占比 vs C2 带；方式1 对比另报标签一致率与边界带翻转率（M4-6）。
- **bootstrap CI**：主配置 seed=20251004 的池化 OOF 上，B=1000、95% 百分位 CI（macro-F1、严重类 recall、严重类 precision）。
- **种子与可复现**：LGBM `seed=20251004`/`deterministic=True`；所有切分/重抽/搜索随机源均登记于日志头。

### 4.7 复杂度、收敛性、失败处理（Q3）

- 复杂度：主配置 3 种子×5 折×(内层 4 折×3 个 γ) ≈ 180 次拟合 + 消融 7 配置×(5 折+1 切分) ≈ 42 次 + 方式1 ≈ 18 次，LGBM 多分类单次 2–4 s，合计 8–12 分钟 → 单脚本（§6 a6_05），超预算时先砍方式1 的 φ 内层（用全量 φ_final）并记日志。
- 收敛性：softmax 多分类 + 早停同 §3.8；类权重 ≤ (n/(3·n_严))^1 ≈ 11 量级（若 s_严=3%），梯度有界稳定。
- 失败处理：若某折严重类验证计数=0 → 该折 recall 记 NaN 并在汇总中注明（3 种子下预期不触发，V8 已保证）；概率标定异常（OOF log loss 相对基线恶化）→ N4-05 回退：主族换 M3-6 均衡集成并记录上报；附件1 标签文件缺失/与 clean 行数不符 → 断言失败停步。
