## 0. 背景与业务链条（题面还原）

- 业务背景：物流履约产生丢失/破损等问题 → 客户提交索赔 → 企业赔付。理赔服务分**售前**（提前发现风险、推荐物流保障服务）与**售后**（控制理赔成本、减少超额赔付）两部分。
- 核心定义（题面原文给出）：
  - **索赔差额 = 实际赔付金额 − 索赔金额**。
  - 对已完成谈赔的历史运单，实际赔付金额可与客户原始索赔金额比较，用以判断诉求是否合理。
  - 三种处置策略：合理诉求 → 快速理赔；诉求偏高 → 交证据 + 人工审核 + 协商；严重超额 → 严格谈赔标准 + 人工审核重点关注。
- 数据：附件1 = 历史运单（已完成谈赔，含实际赔付金额与索赔金额）；附件2 = 未来需要判断理赔服务的运单。特征解释见附表1（运单特征/客诉特征/行为特征三大类 22 个字段）。

## 1. 问题 1：风险标注模型

### 1.1 目标
对附件1全部运单，基于"理赔差额（索赔差额）"与"实际赔付金额"两个量，建立**风险标注模型**，把每张运单标注为三类之一：**合理诉求 / 诉求偏高 / 严重超额**，并给出标注结果与分析。

### 1.2 题面硬性要求与软约束（逐条转写为可检验条款）

| 编号 | 题面依据 | 可检验条款 |
|---|---|---|
| C1 | "标注成'合理诉求'、'诉求偏高'、'严重超额'三类" | 每张附件1运单恰有一个三类标签，无缺失 |
| C2 | "严重超额的运单占比不会太高（通常小于 3%）" | 严重超额占比 < 3%，需在结果中对照报告 |
| C3 | "'合理诉求'的运单不低于 85%" | 合理诉求占比 ≥ 85%，需在结果中对照报告 |
| C4 | "风险标注结果同时与索赔差额和实际赔付金额有关" | 划分规则必须是 (索赔差额, 实际赔付金额) 的二元函数，不能只用一元 |
| C5 | "实际赔付金额越高，则需要更高的索赔差额才会标注为'诉求偏高'或'严重超额'" | 规则中偏高/超额的判定阈值必须是实际赔付金额的**非降函数**（赔付越高阈值越严） |
| C6 | "对于相似实际赔付金额的运单标注时，分成同一类的运单，其索赔差额应尽可能接近" | 同一赔付金额邻域内，同类标签的索赔差额应类内紧凑（可用组内离散度/相邻样本标签一致性检验） |
| C7 | "'合理诉求'的运单索赔差额相对密集，'严重超额'的运单索赔差额相对稀疏，且不同类型的运单索赔差额密集程度之间存在明显差别" | 三类在索赔差额轴上的分布密度需有明显差异；合理类密集、严重超额类稀疏（可用分位间距/密度曲线对照检验） |
| C8 | "需详细说明标注规则如何对运单进行划分" | 规则须有完整数学定义（边界函数 + 阈值/参数 + 估计方法），可复现 |
| C9 | "给出附件1的风险标注结果及分析" | 输出附件1全量标注结果表 + 三类特征/占比/差额分布分析 |

### 1.3 概念澄清（从题面推导）
- 索赔差额 = 实际赔付 − 索赔金额。企业"减少超额赔付"、客户索赔"诉求"，故实际赔付一般 ≤ 索赔金额，索赔差额通常 ≤ 0；差额绝对值越大（赔付相对索赔越低），客户诉求越偏离实际，越可能"偏高/严重超额"。该符号约定由 A3 用数据核实。
- "实际赔付金额越高需要更高索赔差额才标偏高"（C5）与"同一赔付金额邻域同类差额接近"（C6）联合指向：**划分边界应为随赔付金额单调上升的曲线（或分段函数），且相邻金额带内边界取值唯一**。

### 1.4 问题1的自定评价指标（从 C2/C3/C6/C7 推出）
- S1 占比合规性：严重超额占比 <3%、合理诉求占比 ≥85%（软约束对照报告）。
- S2 单调性：边界函数对实际赔付金额非降（数值验证）。
- S3 类内紧凑度：在赔付金额分箱内，同类索赔差额的组内标准差/极差；同类样本的差额密集程度差异（C7 用密度或分位宽度度量）。
- S4 规则简洁性与可解释性：边界可用少量参数表达，便于问题3复用与论文说明。

## 2. 问题 2：附件2 实际赔付金额预测

### 2.1 目标
以附件1（含真实实际赔付金额）为训练数据，用运单特征（附表1 所列）建模，预测附件2每张运单的**实际赔付金额**。

### 2.2 题面硬性要求
| 编号 | 依据 | 条款 |
|---|---|---|
| P1 | "建立模型，预测附件2中运单的实际赔付金额" | 输出附件2逐单预测值，非负实数 |
| P2 | "需说明预测结果的评估指标" | 论文明确写出评估指标定义与训练集上的实测数值 |
| P3 | "将预测结果填写在 result 文件中，不要改变表格中的运单号" | 写入 data\Result.xlsx 模板结构，运单号逐行不动 |
| P4 | 题面方式1："预测实际赔付金额，根据预测值与客户提交的索赔金额比较，判断属于哪一类" | 预测值还须可与索赔金额比较生成风险标注（供问题3路线B对比用），故预测须尽量准确且保序 |

### 2.3 自定评估指标（从 P2 与回归通用实践推导，A2 提供方法论依据）
- 主指标：MAE（与金额同量纲、对大额误差稳健、业务可解释为"平均每单赔错多少元"）；
- 辅指标：RMSE（惩罚大误差）、MAPE 或 WAPE（相对误差，便于跨金额段比较）；
- 评估方式：附件1 上 K 折交叉验证 + 留出验证（A3/A5 细化）；另须检查预测值非负、与索赔金额的序关系合理性（实际赔付 ≤ 索赔金额 的样本占比在预测中保持）。

### 3.2 题面硬性要求
| 编号 | 依据 | 条款 |

### 3.3 自定评估指标
- 类不均衡下的指标：宏平均 F1（主）、加权 F1、每类精确率/召回率（重点看"严重超额"召回）、混淆矩阵；
- 两路线对比：同一验证折上，路线A（直接分类）与路线B（回归预测赔付 → 与索赔金额比较 → 按问题1规则判类）的宏 F1 与严重超额召回对比。
